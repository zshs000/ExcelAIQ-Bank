## 修改与重新生成

内容在 `content.js`，页面样式在 `style.css`，蛋糕样式在 `cake.css`，交互在 `app.js`，页面结构在 `page.html`。

```powershell
python anniversary/build_page.py
```

`history.json` 保留本次核查快照。如需更新主分支历史，先同步远端，再重新提取：

```powershell
git fetch origin master
python anniversary/build_history.py
python anniversary/build_page.py
```

这两个脚本只读取 Git 历史并写入本目录，不修改已有提交或业务代码。更新数据后，应重新核对手工策划的节点和章节。
